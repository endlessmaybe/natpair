## 原发布验证

原 1.2.0 发布摘要记录 118 项回归通过，并包含：

- 八人全互连的 28 对真实 UDP 通道。
- 四人星形的三条房主认证通道。
- 无房主等待、重复房主拒绝、成员退出重进、原生 IPv6 跳过。
- 两个辅助代理隔离、实际 Windows EXE 的三人星形检查。

本次 306 项是对公开源码更广的既有测试发现结果，不把两次统计相加为独立用例总数。原发布摘要已经去掉个人地址、会话和完整诊断记录，见 `RELEASE_VALIDATION.json`。

## 证据边界

本次没有启动新的 Minecraft 世界，也没有进行多台真实 Windows 的原生 Tailscale 游戏认证验收。代理隔离测试使用真实 UDP / AEAD 与合成 Tailscale 报文，不能替代多台真实客户端的完整业务验证。

自有公网服务器连通检查不等同于两端都处于 NAT4；本地八人检查也不等同于八名不同运营商用户。共存预算是软件估计，不是完整 NAT 映射表，未提供 Bifrost 高负载永不掉线的保证。
