# 网络选择、使用提醒与免责声明

适用版本：NATPair Mesh 1.2.0。以下是使用建议与风险告知，不代表软件会自动识别运营商或强制禁用某种网络。

## 网络怎么选

1. **移动 Wi-Fi 优先 IPv6。** 使用移动 Wi-Fi、移动热点等公网 IPv4 或端口映射变化频繁的网络时，不建议使用 IPv4 打洞；优先使用 IPv6 原生直连，不要靠提高发包强度反复尝试。
2. **房主最好有可用的公网 IPv6。** 尤其房间有上述移动网络玩家时，优先选 IPv6 可用、网络稳定的房主。IPv6 原生直连需要连接双方都有可用的公网 IPv6，仅房主有 IPv6 不够。
3. **两两互联时，移动 Wi-Fi 最好别加入 IPv4 打洞。** “全员互连”不是星形组网，每两人都可能需要建立连接；一个公网映射不稳定的成员会增加多对连接的探测与失败。此类成员优先走已经验证的 IPv6 直连，或改用适合的星形房间与稳定网络。

这里主要针对公网出口或端口映射不稳定的移动网络，不表示所有动态 IPv4 都无法打洞，也不保证所有 IPv6 网络都能直连。

接入 Tailscale 时，先确认双方已经通过公网 IPv6 建立原生直连，再使用已有路径。Tailscale 分配的内部 IPv6 地址不等于运营商已提供公网 IPv6。若尚未确认原生路径且不想进行 IPv4 辅助打洞，就先不要启动 NATPair 探测；1.2.0 在确认原生直连后才跳过对应成员对的辅助扫描。参见 [Tailscale IPv6 说明](https://tailscale.com/docs/concepts/ipv6) 与 [连接类型说明](https://tailscale.com/docs/reference/connection-types)。

## 使用前与联网过程中

- **使用前关闭防火墙、杀毒软件和代理软件。** 接入模式所需的 Tailscale 保持运行；关闭的是其他代理软件。代理应正常断开并退出，确认本机网络恢复正常后再联机。
- 关闭安全防护会增加风险，请只在可信环境测试，使用结束后及时恢复防火墙和杀毒软件。
- 联网过程中，较多 UDP 发包可能暂时造成连接不畅、延迟上升、丢包或其他应用短暂断联。请提前保存工作，避开重要下载、远程操作和其他不能中断的任务，避免不必要的损失。
- 出现明显网络异常时，停止探测并等待网络恢复；不要反复重启程序或持续提高发包强度。
